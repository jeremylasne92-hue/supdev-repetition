# Outil d'apprentissage de la classe

Construit par une classe de Bachelor de SUP de V le 17 novembre 2026, pendant l'atelier « Augmenter votre cerveau, pas le remplacer » animé par Jérémy Lasne (Mouvement ECHO).

**Utiliser l'outil :** https://jeremylasne92-hue.github.io/supdev-repetition/

Vos notes et vos cartes restent dans votre navigateur : rien n'est envoyé sur internet.

## Comment il a été construit

1. La classe a choisi le nom, le design et les grandes fonctionnalités.
2. Chaque étudiant a décrit une fonctionnalité dans un mini PRD, après s'être fait interroger par son IA gratuite.
3. Chaque mini PRD est devenu un ticket (onglet *Issues*).
4. La classe a voté. Un agent IA, Claude Code, a construit les fonctionnalités retenues en suivant `CLAUDE.md`, le document de vérité du dépôt.
5. Chaque auteur a vérifié que sa fonctionnalité faisait ce que demandait son mini PRD.

## Améliorer l'outil en commun

Avec un compte GitHub gratuit :

- **Proposer une fonctionnalité ou signaler un défaut :** onglet *Issues*, puis *New issue*, modèle « Mini PRD ».
- **Proposer une modification :** copiez le dépôt (*Fork*), modifiez-le, puis ouvrez une *Pull request*.

## Le personnaliser pour vous

- **Avec un compte GitHub :** *Fork*, puis *Settings* > *Pages* > *Deploy from a branch*, branche `main`, dossier `/ (root)`. Votre copie aura sa propre adresse.
- **Sans compte :** *Code* > *Download ZIP*, puis ouvrez `index.html` dans votre navigateur.
- **Avec une IA :** donnez-lui `CLAUDE.md` et le fichier à modifier, et décrivez ce que vous voulez comme dans un mini PRD.
